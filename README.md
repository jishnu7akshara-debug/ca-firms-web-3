# Tickmark Talent — CA / CS / Tax recruitment website (version 3)

Double-click `index.html` to open. Photos, videos and animation libraries are stored locally; fonts included — works fully offline.

```
index.html
assets/
  fonts/            Syne, Instrument Sans, IBM Plex Mono (woff2)
  css/style.css     styles — 60-30-10 palette tokens at the top (ivory / burgundy / gold)
  js/main.js        preloader, image trail, video-in-type, panels, converge gallery, drag slider, odometers, forms
  js/vendor/        gsap, ScrollTrigger, lenis
  images/           17 photos (Unsplash licence)
  video/            5 clips, 720p (Mixkit free licence) + posters/
```

Before launch: replace brand name, email/phone and service promises; connect the contact form (`#cform` in main.js) to a backend or email service.
